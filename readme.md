# Student Management System (Python)

## Description
A simple command-line based Student Management System built using Python.  
It allows users to add, view, search, and delete student records.  
Data is stored locally using JSON file handling.

## Features
- Add student records
- View all students
- Search student by roll number
- Delete student records
- Persistent storage using JSON

## Technologies Used
- Python
- File Handling
- Dictionaries
- JSON

## How to Run
1. Clone the repository
2. Run the command:
   python main.py
